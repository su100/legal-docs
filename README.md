# legal-docs

su100 이 운영하는 서비스들의 개인정보처리방침·이용약관 등 법적 문서 모음.

## 서비스 인덱스

| 서비스 | 개인정보처리방침 | 이용약관 |
|---|---|---|
| 토마토 장바구니 (toshop-list) | [privacy](toshop-list/privacy.md) | – |

각 문서는 GitHub Pages 로 서빙됩니다:
`https://su100.github.io/legal-docs/<service>/<doc>`

## 유지보수

- 문서 갱신 시 상단 "최종 수정일" 필드 업데이트
- 서비스 종료 시 문서 제거하지 않고 폴더에 `deprecated: true` 마크
- 문의: 각 서비스 문서 내 명시된 이메일
