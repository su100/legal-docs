# 개인정보처리방침 · 토마토 장바구니

**최종 수정일: 2026-08-01**

## 1. 수집하는 정보

토마토 장바구니 는 사용자의 개인 식별 정보(이름, 이메일, 전화번호, 위치 등)를 수집하거나 서버에 저장하지 않아요. 사용자가 입력한 쇼핑 목록은 **기기 내부(AsyncStorage)에만 저장** 되며, 서버로 전송되지 않아요.

다만 앱 개선을 위해 다음의 익명 사용 데이터를 Google Analytics 4 (Measurement Protocol) 로 수집해요:

- **이벤트 이름**: 앱에서 발생한 상호작용 유형 (예: `item_add`, `item_check`, `share_list`, `screen_view`, `easter_egg_tomato_burst` 등)
- **이벤트 파라미터**:
  - `item_name` — 사용자가 추가/편집/삭제한 항목의 이름 (예: "우유", "빵")
  - `platform` — iOS / Android / Web
  - `app_version` — 앱 버전
  - `session_id` — 앱 세션 식별자 (기기별 임시 값)
  - `engagement_time_msec` — 세션 참여 시간
  - 이벤트별 추가 파라미터 (예: 항목 개수 `count`, 핀 여부 `pinned`)
- **client_id** — 앱 기기별로 자동 생성되는 임의의 식별자 (32자리 문자열). 개인 정보와 연결되지 않으며, 앱을 재설치하면 새로 생성돼요.

## 2. 사용자가 입력한 데이터의 처리

- **쇼핑 항목 이름(item_name)** 은 앱 사용 패턴 분석을 위해 GA 로 전송돼요. 이름 자체는 사용자가 자유롭게 입력하는 값이라 개인 정보(예: 실명, 전화번호, 주소 등)가 포함되지 않도록 주의해 주세요.
- 개인 정보가 포함된 항목명은 앱에서 삭제해 주세요. 이미 전송된 이벤트는 GA 콘솔의 데이터 보존 기간 종료 시(기본 14개월) 자동 삭제돼요.

## 3. 데이터의 저장 위치와 보관 기간

- **로컬(기기)**: AsyncStorage, 사용자가 앱을 삭제할 때까지 유지
- **Google Analytics**: Google 서버, GA 콘솔 설정에 따라 최대 14개월 보관 후 자동 삭제
